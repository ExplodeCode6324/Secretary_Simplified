# 身份、授权与隔离

## 1. 信任模型

可信：Master 的本地认证控制入口、安装时固定的协调器与适配器代码、明确批准的运行配置。低信任：用户引用材料、网页、文件正文、子会话模型输出、检索结果、模型生成的参数。来自 Master 的数据内容也可能是引用，不能因为位于用户消息中就提升为控制指令。

威胁范围是模型误用工具、提示注入、任务工作区含恶意文件/配置、崩溃后的旧执行者。初版不声称抵抗已控制本机账号/内核的攻击者。网络服务默认不开启，仅私有 Unix socket；不修改远程机器或开放公网。

## 2. 控制面身份

state root 0700，数据库/对象/配置/凭据 0600，socket 0600。客户端通过仅可信进程可读的本机令牌认证；程序映射固定 Master principal，不接受模型填写的主体字段。日志不得输出令牌。worker 通道用启动时生成的独立随机令牌并绑定 attempt/epoch，不能复用 Master 令牌。

主模型仅有内部查询/提案/任务工具；子模型仅有任务工具。直接修改事实、授权、工作目录范围、模型网关和扩展代码的接口都不暴露给子模型。

权限类别：`fs.read / fs.write / process.exec / http.fetch`。主会话内部服务调用使用固定内部角色能力，不与外部任务授权混合。原型 profile 可预先批准专用合成目录里的读/受控写/命令；具体资源根由可信启动配置提供。任意模型输出的“我获准了”没有效果。

## 3. 执行网关与命令环境

初版本机采用 macOS 强制沙箱进程包装，P1 验证可用的 `sandbox-exec` 配置与 OS 版本；不能运行或测试失败即将 process.exec 标为不可用，不回退宿主 bash。若目标系统不支持该边界，另立 ADR 采用隔离 VM/专用执行账号并通过同一测试；只读 broker 可先运行。

包装器为固定受信任代码，生成 deny-default profile：仅允许工具必需系统只读路径、明确授权的输入文件、专用工作目录与本次 temp；禁止访问 state root、模型凭据、socket、SSH agent、用户配置与其它项目。命令网络默认禁止，工作目录不加载 shell rc 文件。使用受控环境白名单和固定 PATH，不继承 HOME 内私有配置、代理令牌或密钥。stdin 关闭或显式提供，stdout/stderr 有总字节上限。

文件 broker 通过受控打开操作检查实际目标，拒绝目录穿越、符号链接逃逸、设备文件、FIFO 和不受控硬链接。写入采用同目录临时文件与原子替换；对可变输入记录读取时版本/hash。不能依赖“字符串路径以根目录开头”作为最终判断。

本版采用原生根目录 FD/openat broker，受控目录内串行版本写；任意宿主目录的并发 CAS 不作保证。进程监督、沙箱生产策略验证及 HTTP 固定 IP/TLS 规则见 [RuntimeProtocol](RuntimeProtocol.md) 第 7 节。

不允许子模型加载 npm 插件、修改可执行 adapter 或执行器配置。被授权运行测试目录内的一般脚本仍是通用命令能力，但脚本的文件/网络权限受相同沙箱限制。取消操作终止整个进程组并确认无遗留子进程；无法证明停止则保持未知状态。

## 4. 网络与数据外发

`http.fetch` 初版只提供 GET/HEAD，域名/端口在任务 grant 中，跟随重定向时逐跳重验。拒绝 file 等其它协议、未经授权的本地/链路本地/私网地址、DNS 重绑定和代理旁路；允许私网必须显式资源授权。读取目标不等于允许向另一目标上传其内容。

模型数据分类为 `SYNTHETIC / PUBLIC / PERSONAL / SECRET`，聚合采用最严格等级。主/子/整理/语义验收/所有重试都走同一 provider policy。默认只允许 SYNTHETIC，未配置 provider 时无真实调用。SECRET 默认不可外发；不能由模型降级分类。日志、引用和派生摘要继承分类。

provider 身份、base URL、TLS 和允许分类来自可信配置；不允许模型传任意 endpoint。网关在最后发送边界重验允许分类与最终载荷，关闭 provider 隐式重试或把每次真实尝试纳入预算；禁止失败后静默换到另一个提供方。

## 5. 提示注入与证据

检索/网页/子报告以引用块和来源元数据进入输入。引用中要求更改系统规则、授权或执行工具的文字只能作为内容。执行器从持久 grant 与任务版本决定权限；事实接纳从证据和政策决定；不依赖模型每次正确识别恶意内容。

模型输入里的权限提示仅帮助选择合法操作，不是权限本身。校验、日志或沙箱失败一律拒绝受保护动作，明确报告暂停原因。安全相关回归为独立阻断项，不与平均任务成功率相抵消。

# 增量记忆模板 v1.0

输入是明确的连续源事件段、原始证据引用及当前权威任务/义务/事实索引。仅整理这段新增经历，不把检索参考、先前摘要或模型推断重新当作发生过的原始事实。

输出符合 EpisodeDraft：from_seq、to_seq、summary、task_ids、obligation_ids、fact_ids、coverage、missing；公共 schema_version 和 record_type 按契约填写。

保留用户要求、禁止条件、决定及理由、实际结果、未决问题和证据。已有权威任务/义务 ID 原样引用；不能自己宣布其完成或撤销。每个输入事件都给覆盖分类；不能理解或信息不足标 PENDING 并列入 missing，不能为推进水位编造处理完成。

不输出授权决定，不修改世界模型。发现新事实或新义务只作为待处理信息由主流程判断。来源冲突保留冲突；未知时间不补猜。summary 是可重建理解视图，不承担唯一权威状态。

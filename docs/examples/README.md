# 契约样例

[manifest.json](manifest.json) 列出每个样例的类型及预期接受/拒绝结果。每个主 DTO 有一个合法结构样例；非法样例覆盖伪造授权字段、未知字段/状态、版本、UUID、时间、数值和缺失字段。

这些样例是 **STRUCTURE_ONLY**：重复使用合成 UUID，不构成跨对象真实数据集；Schema 通过不代表身份已认证、引用存在、授权有效或语义正确。跨对象引用、事务、状态和恢复由附件检查及后续运行测试另行验证。

[tool-cases.json](tool-cases.json) 补充实体解析、义务解决、文本产物入口的参数及拒绝自授予权限字段的正反例。关系值互斥、许可消费/撤销互斥和回复 task/version 成对也有独立反例。

后续实现把本目录用作解析兼容性样例，不将其直接导入真实数据库或用于真实模型输入。

## 一、对 substring 锚点规则的复裁

协调方反对成立。我方撤回第一裁决中的锚点/来源契约，并说明理由：

1. substring 存在性不能证明授权：否定（"不要迟到就跳过"含子串"迟到就跳过"）、引用、注入、无关片段均可令原文包含指定子串。包含性检查不具备证明力。
2. 模型自填锚点字段与该机制同病：属自我声明，非可验证证据；"新增模型锚点字段"确实不解决问题（协调方判断正确）。
3. 因此原裁决二.2（来源契约）与 C2 一并作废，且不得以叠加方式保留——substring 不再作为任何接受/拒绝依据，包括辅助检查。

根本转变：授权锚定在"通道"（传输路径），而非"文本"（语义解读）。这是可验证性的来源。

## 二、对 v1 契约的裁定：同意

同意 v1 作为替代方案，且同意其为"更小可安全实现"的最小边界：

1. 唯一硬判据是确定性的：决策来源 == 自然语言，且提醒迟到策略 != FIRE_ONCE_WITHIN_GRACE/300s → 拒绝，reason = REMINDER_POLICY_UNSUPPORTED。无需语义解释、无需锚点、不引入数值阈值。
2. 再往下缩即要么放弃默认强制（回到静默跳过的原风险），要么剥夺已建成的 Typed 能力（超出本事故范围）。故 v1 在不降低可验证性的前提下已是最小。
3. 明确这是限制 NL 策略表达的 v1 契约：文档不得声称支持任意 NL 策略语义；未来若要扩展，须走新设计评审，不得静默扩权。

成立性所需的最小补充（K1–K5，均为此方案自洽所必需，非新增门槛）：

K1 通道互斥：Typed 迟到策略字段仅可由用户认证通道写入；模型与决策服务均不得代填、改写、回转。发现代填即整体否决——否则"通道授权"前提不成立。
K2 重试上限固定：单一决策周期内最多 1 次重试（模型生成总计 ≤2 次），重试必须携带拒绝码与补救指引；固定常量、非自适应、不设时间窗。超限即硬失败、零副作用、记录保留。
K3 拒绝原子性与"无副作用"定义：整决策事务拒绝 = 不落任何提醒、不改 Item 状态、不产生通知、重复扫描幂等（重扫不产生任何副作用）。
K4 反馈与系统说明一致：系统说明与拒绝反馈均须含"不支持自然语言自定义迟到策略，请用 Typed"的补救指引；不得以默认策略静默冒充用户明示的非默认意图（不得静默替换用户意图）。
K5 文档同步：ExecutionProtocol（默认强制 + NL 自定义不支持）、Interfaces（拒绝码、Typed 通道写权限边界、重试上限）、Acceptance（下节 4 测试为固定 criteria）、README（实施发现与本 v1 限制）。

不变项：Scheduler 严格 grace 算法不动；既有 oracle 不动；run1 保留不动；不做模型返回后静默改值；不做程序默认回填。"once"仅为通知次数语义，不构成 SKIP 授权——须写入系统说明与契约文档。

## 三、与任务行为 / 固定 criteria / 重试上限的关系

任务行为：
- NL 提醒计划 → 必须协议默认 FIRE_ONCE_WITHIN_GRACE/300s；首扫处于宽限内恰好一次通知，Item 保持 OPEN。
- NL 偏离默认 → REMINDER_POLICY_UNSUPPORTED，整事务拒绝、无副作用、反馈模型、最多 1 次重试。
- 已认证 Typed 显式字段（如 SKIP0）→ 原样保留，按既有 Scheduler 严格算法执行（SKIP 即 SKIP，不通知）。
- 来源信息在决策时不可判定 → 走保守侧（拒绝 + 显式报错），不得默认放行。

固定 criteria（4 测试，不降标、不加阈值）：
T1 默认 NL 准入：无偏离即接受，策略字段等于默认值。
T2 非默认 NL 拒绝且无副作用：拒绝码正确 + K3 全部零副作用 + 幂等。
T3 已认证 Typed 明示 SKIP0 保留：不被拒绝，执行结果符合协议。
T4 相同原话 + 相同 oracle 的真实 CLI 重跑：run1 处置不变；期望"默认决策 + 宽限内恰好一次通知 + Item OPEN"；任何失败照原样入档。

重试与复测规则（对"二试即报"的边界，按协调方要求）：
- 运行时重试上限 = K2（≤1，固定并文档化）。
- 每次失败（run1、run2…）原样保留入档；禁止为通过而反复重跑。
- 有依据的修复后可复测，不设新的 Master 审批门——"二试即报"仅为操作侧汇报习惯，不作为本契约的审批机制被挪用。
- 验收标准不因复测变更。
